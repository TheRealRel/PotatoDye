# Changelog

## 1.0.1
- The mod page links the author's Discord for questions (bug reports stay on GitHub) and has a License section: the code is MIT, free to use, change and share; the icon is CC BY-NC 4.0.

## 1.0.0
- First release: a Cape color panel at the barber with hue, saturation and brightness sliders (each showing the colors it reaches), a live preview, Apply and Cancel, and a No dye button. Colors are saved with the character, one per kind of cape, and follow the cape you see (Vanity Outfit included).
